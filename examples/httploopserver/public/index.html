It works

This page is served by httploopserver, a small HTTP server written in Pascal: netloop event loops (epoll / kqueue), its routes by the netrouter unit.

  • /status: a page the server makes
  • /hello.txt: a plain text file (the /* route)
  • /hello/{name}: a URL parameter
  • /posts/{id:[0-9]+}: a parameter with an expression
  • /api/echo/{word}, /api/routes: a JSON sub-router
  • /missing: a 404
